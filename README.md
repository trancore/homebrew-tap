# trancore Homebrew tap

English | [日本語](./README.ja.md)

`trancore/tap` is the Homebrew tap for trancore tools.

## Packages

- [`figfig` formula](./Formula/figfig.rb) · [Installation, upgrades, and removal](https://github.com/trancore/figfig/blob/main/website/i18n/en/docusaurus-plugin-content-docs/current/getting-started/installation.md)

## For maintainers

The `Update Homebrew tap` workflow in the source repository verifies and updates the formula after a release is published. Tap CI tests the formula on Apple Silicon and Intel Macs.
